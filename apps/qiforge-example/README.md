# qiforge-example (Node runtime) — ⚠️ DEPRECATED

This is the reference oracle for the **deprecated** Node runtime
(`@ixo/oracle-runtime`, `packages/oracle-runtime`). It is no longer developed
and only kept so the package keeps building.

The live reference app is [`apps/qiforge-workers-example`](../qiforge-workers-example)
on the Cloudflare Workers runtime (`@ixo/oracle-runtime-workers`). Start there.
`WEATHER-PLUGIN.md` in this directory still documents how a plugin is written;
the same plugin class runs unchanged on the Workers runtime.
