- [#350](https://github.com/ixoworld/qiforge/pull/350) [`00cbd28`](https://github.com/ixoworld/qiforge/commit/00cbd28d57942853f79757597ecb79ebc64b7dae) Thanks [@Michael-Ixo](https://github.com/Michael-Ixo)! - Bound every model call by stream liveness instead of the turn deadline. A `fetch` guard on every platform (OpenRouter, Nebius) and BYO model watches the raw response bytes: no headers within `LLM_HEADERS_TIMEOUT_MS` (120 s) or no first byte within the idle budget re-sends the identical request up to `LLM_STREAM_RETRIES` times (default 1, at most 5, clamped per lane so every attempt fits `TURN_TIMEOUT_MS`: with the defaults the platform lane keeps one retry and BYO lanes get none); silence after bytes were forwarded fails the call at once. A stall reaches the client as `kind: timeout` ("The model stopped responding mid-reply" / "did not start responding") and counts as an unknown outcome for write claims; LangChain no longer retries a stall the guard gave up on, and the OpenAI SDK timeout becomes a backstop behind the guard instead of its 10-minute default. Model calls now log `[llm] start` / `end` (debug) and a `still running` heartbeat every 60 s; completed tool calls log `[tool-execution] <tool> (<id>): ok in N ms` (debug). Firecrawl's `firecrawl_search` and `firecrawl_scrape` are declared `effect: 'read'`, so they are no longer scheduled, claimed and capped as writes.
