# Weekly Report

Roll up a topic's last 7 days into a single digest.

**Trigger:** `time.cron` weekly — typically `0 9 * * 1` (Monday 9am).

## What to do

Collect what happened on the topic over the last 7 days. Use whichever
research tools the agent has — Memory plugin for prior context, Composio /
Firecrawl for the public web, Sandbox for any analysis the user asked for.

## How to report

Sectioned markdown:

- **Highlights** — 3-5 bullets.
- **Why it matters** — one short paragraph.
- **Sources** — linked list.

## Constraints

- Under 500 words.
- Skip filler; if nothing happened, say so in one line and stop.
