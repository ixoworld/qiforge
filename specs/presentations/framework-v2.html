  name: 'My Oracle',

07 / 13

What got faster.

  • On-demand loading shrinks per-turn context.Fewer tokens, lower cost, lower latency on every turn.
  • First request per user warms a local DB.Subsequent requests skip the sync entirely.
  • Subscription credits use a 3-min cache.Cache hits skip redundant writes to the network.
  • State reads use the checkpoint directly.No more rebuilding a throwaway agent just to inspect state.
  • Messages pipeline: 1490 lines → 210-line orchestrator over 6 focused services.Clearer fast path, fewer allocations, simpler to reason about.

The wins compound on every turn.

class WeatherPlugin extends OraclePlugin {
  name = 'weather';
  manifest = { title: 'Weather' };
  getTools() {
    return [tool('forecast',
      z.object({ city: z.string() }),
      async ({ city }) => fetchForecast(city))];
  }
}
