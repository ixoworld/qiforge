## Architectural decisions (binding)

### From earlier sessions
- **UCAN-only auth** — no Matrix OpenID fallback in the new runtime
- **Use `ioredis` Redis directly** — don't abstract via a port
- **No type assertions** to fix type errors — find actual mismatches (cross-package langchain version skew is a documented exception)
- **Reuse, don't blindly copy** — lift apps/app code only if it aligns with plugin contracts; otherwise stop and propose reimpl with user sign-off
- **Stop-and-report between subagent waves** — don't auto-chain multi-task plans
- **No wrapper packages around 3rd-party SDKs** — install directly into consuming app
- **No task/spec metadata in source comments** — comments for runtime/architecture only
- **NEVER add Co-Authored-By lines or "Generated with Claude" attribution** in commits/PRs

### From this session
- **`OracleRuntimeBundleHolder`** — Nest provider populated post-bootstrap. Solves chicken-egg between Nest DI lifecycle and `AmbientServices` (which depends on DI-managed UcanService). Documented in `specs/tasks/README.md` "Bootstrap pattern".
- **Drop `SUBSCRIPTION_UCAN_PORT`** indirection — UCAN is core runtime, inject `UcanService` directly. Keep `SUBSCRIPTION_CREDIT_SINK` port (credits IS a plugin).
- **Default checkpointer hook lives in `createOracleApp`** — `bundle.hooks.checkpointerForUser` wired from `UserMatrixSqliteSyncService`. Host opts can override; `AgentBuilder` never overrides.
- **`getTuple` for priorState reading** — same call LangGraph itself makes; with TODO to verify in smoke
- **`version: 'v2'` REQUIRED for streamEvents** — pass in 2nd arg (config), not 3rd. Without it stream is silent or v1-formatted. `langGraphConfig` typed as `Record<string, unknown>` to escape TS strictness on the streamEvents config union.
- **SSE headers set in the RUNNER (not controller)** — so `X-Request-Id` + `Access-Control-Expose-Headers` are on the response. Earlier "early flush" optimization broke FE clients.
- **`MEMORY_ENGINE_URL` is OPTIONAL** — both `messages.module.ts` and `sessions.module.ts` factories now return `null` when env is missing; SessionManagerService accepts undefined and skips memory enrichment
- **`SUBSCRIPTION_URL` is OPTIONAL** — falls back to `getSubscriptionUrlByNetwork(network)` from `@ixo/common`
- **Per-process `syncedUsers` Set** — first request per user syncs Matrix→SQLite; subsequent skip. Cleared in `clearLocalCheckpoint` AND hourly cron when local files deleted (otherwise the Set would be stale after the cron)
- **`type` imports of Nest-injected classes** are a BUG — TypeScript strips them at compile time, `design:paramtypes` ends up `Function`, Nest DI fails. Always use VALUE imports for any class in a constructor parameter. See `ucan.service.ts` and `session-history-processor.service.ts` for examples.
- **EditorPlugin doesn't expose its configSchema publicly** — the matrix env vars it parses are in the core base env schema; re-declaring them via `OraclePlugin.configSchema` causes schema-composer dup warnings on every boot
- **Skip `syncCreditSink` on subscription cache hit** — Redis was already synced on miss; the 3-min cache TTL is the source of truth for "fresh enough"

### Request lifecycle (chat happy path)

```
POST /messages/:sessionId
  → AuthHeaderMiddleware (UCAN validate, cache, set req.authData)
  → SubscriptionMiddleware (gate on subscription/credits; mirrors to Redis via SUBSCRIPTION_CREDIT_SINK)
  → ThrottlerGuard
  → MessagesController.sendMessage
    → MessagesService.sendMessage
      → RequestPreparer.prepare (session, room, runnableConfig)
      → assembleInput (HumanMessage + file attachments)
      → matrixManager.sendMessage (replay user msg — fire-and-forget)
      → SseStreamRunner.run (if stream)
        → setSSEHeaders(res, requestId) + flushHeaders + heartbeat
        → emit Thinking event
        → AgentBuilder.build (reads priorState, builds requestCtx, calls createMainAgent)
        → agent.streamEvents(stateInput, {version:'v2', ...config})
        → for-await: map on_tool_end → ToolCallEvent/ActionCallEvent; on_chat_model_stream → reasoning chunks + message chunks
        → onComplete: matrix replay AI msg, firePostSync
      → BatchInvoker.invoke (if !stream)
    → PostMessageSyncer.run (fire-and-forget — uses getUserDatabaseNoSync)
```
