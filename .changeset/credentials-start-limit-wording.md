Credentials plugin: Self's identity-check start limit is told kindly and truthfully. A new link refused with `429 daily_limit` now says when the person can try again as a friendly duration computed at the time of speaking ("You've used your 3 tries for now. You can try again in about 5 hours. Just message me then and I'll send you a new link."), from `resetsAt`, else `retryAfterSeconds` / `Retry-After`, else "later today", never the generic "Too many requests right now. Please try again in a minute." The answer carries `limit` (resetsAt, retryAfterSeconds, tryAgain, startsLeft 0, startsMax, windowHours) and a hint never to offer a new link before then. A failed check says the tries left ("You can try 2 more times.") or, with none left, the wait instead of "ask me for a new link"; an unstarted link whose start Self refused is not sent again. New failure `too_many_photos` (Self's `failureReason`) has its own words. The failed `identity_check_updated` reply carries the structured facts as `facts` for a plugin that words it itself; `ChannelEventResult`'s `reply` gains the optional `facts`. Exports: `failedAnswer`, `friendlyWait`, `startsLeftSentence`, `limitSentence`, `limitWait`, `startsOf`, `limitAnswer`, `limitHint`, `START_LIMIT_CODE` and their types.
