Attachment bytes are no longer stored with the conversation. A file the model reads natively stays inline, as base64, only in the turn's in-memory state; the checkpointer stores every message that carries such blocks (the person's message and the `view_attachment` re-attachment) with one placeholder text in their place, listing each attachment with its reference, in message rows, checkpoint blobs and pending writes alike. The attachment metadata is kept, so transcripts are unchanged. Before, the bytes sat in the checkpoint and were replayed on every model call until a turn completed and the retention pass rewrote turns older than the newest two; a large file could reset the user's Durable Object mid-turn, before that pass ever ran. The retention pass is removed. Human message rows stored with their bytes before this version are rewritten to the placeholder once per thread, on the thread's first load (recorded in a new `attachment_payload_sweeps` table). Tool and AI messages that carry base64 (an MCP screenshot) are still stored as they are; the saver logs every write whose serialized form still holds an inline payload.

Images of the newest two user turns are put back into each model request at call time, from their source (Matrix media, channel links, http(s)), downscaled when the oracle binds `IMAGES`: at most 4 per request, fetched one at a time with a 15 s deadline each, none over 5 MiB, at most 10 MiB of base64 per request, never an image the request already carries or the same file twice; finished images are kept in a small per-object cache so later turns neither fetch nor transform them again; a failed fetch leaves the placeholder. When the provider refuses a request with recalled images (a 4xx that is not a context overflow, credential, billing, timeout or rate limit), the call is retried once without them and they are not recalled again in that run. Documents and older images come back through `view_attachment`. A durable run resumed mid-turn sees the placeholder for its own files and recalls its images the same way.
