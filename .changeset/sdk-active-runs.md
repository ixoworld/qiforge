`useActiveRuns(oracleDid, { baseUrl? })` shows which of the user's chats on an oracle are running, for a live status on every chat-list row: it polls `GET /runs/active` every 4 s while a run is active and every 30 s otherwise (and after a failed poll), only while the tab is visible and a wallet is signed in, refetches on window focus, and returns `{ runs, bySession, count, isSupported, isLoading, error, refetch }`. Polls are background requests: `authedRequest` gains a fifth argument, `{ background: true }`, with which a request sends only a cached delegation and never mints one, mints any invocation it needs (none cached, or the stage-1 renewal) with `createInvocation(oracleDid, { background: true })`, and never runs stage 2. `CreateInvocationFn` gains that optional second argument (and may resolve `null`): with `background` the host must mint without any user interaction — no PIN or passkey prompt, without extending the signer's idle timer — or resolve `null`; the request then fails unsent with a 401 `RequestError` (`code: 'BACKGROUND_INVOCATION_UNAVAILABLE'`) and is never retried interactively. Hosts that ignore the argument keep their behaviour, prompts included (the Portal's `useCreateUcanInvocation` is the reference host). `getInvocation` and `renewOracleAuth` take the same `background` option; a background mint goes into the shared cache, and background and interactive mints in flight are never shared with each other. When a poll is refused (by the oracle, or for want of a background invocation), polling pauses until the next window focus. A runtime without the route answers 404 `Run active not found`: `isSupported` is `false` and the hook probes again every 10 min (any other 404 is an ordinary failed poll). A busy chat missing from a loaded `useOracleSessions` list refreshes that list once, and `useChat` refreshes the active runs as soon as a sent message's run has started.

`useAbortSession(oracleDid)` stops the current message of any session with `POST /messages/abort`, not only the mounted chat's: the session leaves the active runs at once (put back if the request fails), then the active runs and the session lists are refreshed. `IChatSession` gains the optional `activeRun` the runtime now sets on busy session rows. New exports: `ChatRunSummary`, `ChatRunStatus`, `ActiveChatRunStatus`, `ActiveRunsResponse`, `AuthedRequestOptions`, `isActiveRunStatus` (`queued` / `running` / `recovering`; `useChat` uses it for its re-join check), `activeRunsQueryKey`, `oracleSessionsQueryKey`, `ACTIVE_RUNS_BUSY_POLL_MS`, `ACTIVE_RUNS_IDLE_POLL_MS`, `ACTIVE_RUNS_UNSUPPORTED_REPROBE_MS`.
