Add DAO DAO governance groups to the catalog. An oracle can now ask the user's Portal wallet to create a DAO DAO group (`/ixo daodao create-group`, the same multisig group the Portal creates: members with one vote each, an absolute number of yes votes to pass, the network's DAO DAO code ids; 7 days to vote and vote changes allowed unless the caller chooses otherwise: a voting time from 1 hour to 30 days, and vote changes on or off) and to propose, vote on, carry out and close proposals of such a group (`/ixo daodao propose|vote|execute|close`). Each message must be exactly one of these shapes, so an arbitrary contract instantiate or execute is refused, and a group is checked against its network's code ids. The wallet still shows every member, threshold and proposal action in readable form; the Portal encoder turns them into the bytes the contracts read. New helpers build these messages (`buildDaoDaoGroupInstantiate`, which takes `votingPeriodSeconds` and `allowRevoting` with the bounds and defaults in `DAODAO_VOTING_PERIOD_SECONDS` and `DAODAO_DEFAULT_ALLOW_REVOTING`, `buildDaoDaoProposalMessage`, `buildDaoDaoGroupLinkMessages`), read the new group's address from the transaction (`findDaoDaoCoreAddress`) and find a message's catalog entry from its content (`findMessageForValue`), since the four proposal steps share one type URL. A proposal discloses what it would do: its risks are its own and those of each action it holds, and its risk level the highest of them (a proposal that would send the group's funds is `high`, one that would retire credits `critical`), in a batch, a single draft and the Portal's consent sheet alike, so the user accepts each action's risks word for word before signing. `daoDaoProposalActions` reads a proposal's actions, and `describeMessageValues` / `describeDaoDaoProposalAction` word a message with its values (recipient and amount of a send, token ids and amounts of a token move). `validateMessage` takes the network as an optional second argument. A linked entity's id may now also be `{id}#<address>`, as the Portal writes it for a group.
